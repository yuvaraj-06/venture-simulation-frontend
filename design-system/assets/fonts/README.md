# Aeonik Pro webfonts

Aeonik Pro is licensed software. This repository deliberately contains **no font binaries** and does not distribute them.

For an authorized Share deployment, obtain the required WOFF2 files through the license-managed internal source, verify that the target domain is covered by the CoType licence, and provide only the required weights to the authorized build/deployment path. Do not commit, publish, attach, or pass the font files to other repositories, agents, vendors, or third parties.

When Aeonik Pro is unavailable, use the sanctioned Arial fallback. The licence terms are retained in `CoType EULA WebFonts Nov 24.pdf`.
